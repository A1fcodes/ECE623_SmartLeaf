SmartLeaf is an early plant stress detection system built using the Nordic Thingy:52. The system monitors environmental conditions around an indoor plant, including light intensity, humidity, and air quality/VOC levels. By analyzing sensor readings over time, SmartLeaf can detect possible plant stress conditions such as low sunlight, dry air, overwatering risk, or poor air quality.

When a stress condition is detected, the Thingy:52 provides local feedback using LED color indicators and sound alerts. For example, low sunlight can trigger a red LED flash and a beep to warn the user that the plant may not be receiving enough light.

The goal of SmartLeaf is to help users identify plant care problems before visible damage occurs.
